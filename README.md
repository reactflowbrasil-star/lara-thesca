# Lara Thesca

Crie uma landing page premium, moderna e visualmente marcante para a artista e criadora de conteúdo de beleza Lara Thesca, com foco no subtema “maquiagem artística com produtos acessíveis”.


foto da hero: https://growmoneydigital.com.br/alexandre/fran.png

OBJETIVO

A página deve apresentar Lara como uma referência criativa em beleza, mostrando que maquiagem artística, looks impactantes e expressão pessoal não precisam depender de produtos caros. O conceito central é:

“Sua beleza é uma tela. Sua criatividade é o limite.”

A landing page deve gerar conexão, desejo de acompanhar Lara e incentivar o visitante a conhecer seus conteúdos, descobrir produtos e explorar seus looks.

DIREÇÃO VISUAL

Crie uma estética editorial de beleza contemporânea, misturando:

luxo fashion com acessibilidade;
maquiagem artística;
fotografia de editorial;
elementos de scrapbook/digital collage;
detalhes cromáticos inspirados em cosméticos;
tipografia elegante combinada com uma fonte display ousada.

Evite aparência genérica de “site de influencer”. A identidade deve parecer uma mistura de revista de moda + beauty studio + portfólio artístico.

PALETA

Use uma base sofisticada com:

off-white/creme;
preto ou grafite;
rosa queimado;
vermelho cereja ou vinho;
pequenos acentos metálicos/prateados.

Utilize cores vibrantes apenas como pontos de destaque.

HERO

Criar uma primeira dobra impactante com uma fotografia editorial de Lara usando uma maquiagem artística marcante.

Headline:

“Beleza não precisa seguir regras.”

Subheadline:

“Descubra maquiagem artística, produtos acessíveis e looks criativos para transformar seu rosto em uma tela.”

CTAs:

Explorar os looks
Conhecer Lara

Adicionar pequenos elementos visuais, como etiquetas, rabiscos, estrelas, pinceladas ou anotações manuscritas, sem poluir a composição.

SEÇÃO “A ARTE DE SE MAQUIAR”

Apresente a filosofia de Lara em um bloco visual editorial.

Mensagem principal:

“Maquiagem não é sobre esconder. É sobre criar.”

Explique que Lara transforma maquiagem em ferramenta de expressão, experimentando cores, texturas, formas e referências artísticas — sempre buscando alternativas acessíveis para que qualquer pessoa possa experimentar.

SEÇÃO DE LOOKS

Criar uma galeria visual de maquiagens artísticas.

Cada look deve possuir:

fotografia grande;
nome do look;
pequena descrição conceitual;
paleta de cores;
botão “Ver detalhes”.

Exemplos:

Cherry Mood — vermelho, vinho e acabamento glossy.
Electric Blue — azul intenso com inspiração futurista.
Soft Rebellion — tons delicados combinados com elementos gráficos.
After Dark — maquiagem dramática para uma estética noturna.

Use uma composição assimétrica e editorial, evitando uma grade convencional excessivamente rígida.

SEÇÃO “BELEZA SEM PREÇO ABSURDO”

Criar uma seção dedicada a produtos de bom custo-benefício.

Headline:

“O look dos sonhos não precisa custar uma fortuna.”

Mostrar cards de produtos acessíveis organizados por categoria:

pele;
olhos;
lábios;
ferramentas;
finalização.

Cada card pode conter:

imagem do produto;
nome;
faixa de preço;
avaliação da Lara;
indicador “Vale a pena?”;
botão “Descobrir produto”.

Não invente marcas, preços ou avaliações reais. Quando dados reais não estiverem disponíveis, utilize placeholders claramente identificados.

SEÇÃO “ANTES DE COMPRAR”

Criar um pequeno guia de compras com dicas da Lara:

“3 coisas que eu observo antes de comprar um cosmético”

Fórmula e acabamento.
Versatilidade.
Custo por uso.

Apresentar como cards editoriais com números grandes e elementos gráficos.

SEÇÃO SOBRE LARA

Criar um bloco mais pessoal.

Título:

“Oi, eu sou a Lara.”

Apresentar Lara como artista, criadora e apaixonada por transformar beleza em linguagem visual.

O texto deve transmitir personalidade, criatividade, autenticidade e proximidade, evitando uma biografia corporativa.

Adicionar uma fotografia espontânea/editorial e pequenos detalhes manuscritos.

PROVA SOCIAL

Criar uma seção para depoimentos/comunidade com frases curtas sobre a influência de Lara.

Exemplo de estrutura:

avatar;
nome;
@username;
comentário.

Utilizar conteúdo fictício apenas como placeholder e deixar claro no código/design que deve ser substituído por depoimentos reais.

CTA FINAL

Criar uma seção visualmente forte para conversão.

Headline:

“Pronta para sair do básico?”

Texto:

“Entre no universo da Lara e descubra novas formas de criar, experimentar e se expressar através da beleza.”

Botão principal:

“Entrar no universo Lara Thesca”

RODAPÉ

Incluir:

logo/nome Lara Thesca;
redes sociais;
contato;
links institucionais;
política de privacidade;
termos de uso.
EXPERIÊNCIA E INTERAÇÕES

A página deve ter:

animações suaves de entrada;
hover elegante nos produtos;
microinterações nos botões;
efeitos de parallax extremamente sutis;
transições fluidas;
galeria de imagens com sensação de editorial;
navegação responsiva.

Evite animações exageradas que prejudiquem performance ou acessibilidade.

RESPONSIVIDADE

O design deve ser pensado primeiro para mobile e funcionar perfeitamente em desktop, tablet e celular.

No mobile:

priorizar imagens e headlines;
transformar galerias em carrosséis quando necessário;
manter CTAs grandes e fáceis de tocar;
preservar a hierarquia visual.
TOM DE VOZ

A comunicação deve ser:

confiante;
artística;
jovem;
sofisticada;
acessível;
divertida;
autêntica.

Nunca usar linguagem excessivamente corporativa ou clichês genéricos de marketing de influencer.

RESULTADO ESPERADO

O resultado final deve parecer uma campanha digital de uma artista de beleza contemporânea, e não simplesmente uma landing page de influenciadora.

Priorize:
identidade visual + desejo + personalidade + descoberta de produtos + conversão.

A experiência deve fazer o visitante pensar:

“Eu quero experimentar esse look.”
“Eu quero acompanhar essa artista.”
“Eu consigo fazer isso sem gastar uma fortuna.”
